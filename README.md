# 🪼 水母的探索日记 · AI 创作资源库

> 到处逛逛，顺便捡点有意思的东西。
> 设计 ｜ 科技 ｜ AI ｜ 奇奇怪怪的小玩意

一个手工策展的 AI 创作作品集：每个作品不只是「看一眼视频」，而是把**完整的中英文提示词**、
**成品演示**、**在线体验入口**放在同一张卡片里。访客看完就能拿走提示词，自己在任意模型里复现。

**线上地址** → <https://fluxtide.github.io/ai-creative-hub/>

---

## 为什么做这个站

小红书和 X 上发作品，提示词永远塞不进正文；评论区里一句句发又散得到处都是。
所以把「视频 + 提示词 + 能点的 demo」做成一个固定地址，谁问就把链接丢过去。

站本身也是个实验场：深海生态、物理拉绳、深海电子宠物，这些交互不是装饰，
是用来验证「一个纯静态页面能有多好玩」的样本。

## 站里有什么

### 12 个作品

每个作品卡片包含：封面、中文描述、双语提示词（一键复制）、工具标签、在线体验直达。
点开卡片是全屏详情视图，正负提示词直接铺开。

目前收录的都是 3D / WebGL 互动玩具方向的实验——毛绒水母、果冻海、锦鲤池塘、
锤头鲨、海盗岛、北极极光浮岛、小鱿鱼、旗鱼……同一个「柔软物 + 物理」母题的不同解法。

### 三个纯手写的 Canvas / SVG 引擎

| 模块 | 是什么 | 技术 |
|---|---|---|
| `jellyfish.js` | 深海电子宠物生态：三阶进化形态、全长页漫游、三段柔性触角、鼠标 / 触摸引力交互 | Canvas 2D，自研软体运动 |
| `seaweed.js` | 底部水草生态带：五物种、岩石微光、发光浮游气泡，随水流摆动 | Canvas 2D |
| `pullcord.js` | 天花板真实物理拉绳，拽一下换主题 | Verlet 质点弹簧 + SVG，零依赖 |

三个都是单文件、零外部依赖，直接 `<script>` 引进来就能跑。

### 7 套莫兰迪配色 × 浅色 / 深色

「外观设置」里可以换配色（云上舞白、繁花如梦、刚玉蓝、猕猴桃绿、辛香红、湖水青、Geist），
每套都配了浅色和深色两版，切换即时生效并记住选择。**新访客默认从浅色进入**，
想用深色或跟随系统，在「外观设置」里选一次即可，之后会记住。

还有一条隐藏路径：右上角那根拉绳拽一下也能换色。

## 怎么看本地效果

```bash
# 纯静态，起任何 HTTP 服务器都行（别用 file:// 打开，视频和 Canvas 都需要 HTTP 环境）
cd ai-creative-hub
python3 server.py            # → http://127.0.0.1:8899

# 或者
npx serve .
```

`server.py` 是自带的开发服务器（基于标准库 `http.server`，无第三方依赖），
它把 `public/` 目录当作站点根。

## 技术栈

**没有框架。** 一个 `index.html` + 一份 `style.css` + 五个原生 JS 文件，构建步骤为零。

| 文件 | 职责 |
|---|---|
| `index.html` | 页面结构：横幅、按钮排、筛选栏、卡片网格、详情视图、各类弹窗 |
| `style.css` | 全部样式与 7 套主题变量（`html[data-theme][data-mode]`） |
| `app.js` | 主题系统、卡片渲染、筛选搜索、收藏、登录注册、邮件验证码 |
| `data.js` | 12 个作品的元数据与双语提示词 |
| `jellyfish.js` / `seaweed.js` / `pullcord.js` | 三个 Canvas / SVG 互动引擎 |
| `server.py` | 本地开发服务器 + 邮件验证码接口 |
| `public/` | 站点镜像目录（`server.py` 的根） |

## 部署

线上跑在 **GitHub Pages**，推送 `main` 后由 `.github/workflows/deploy-pages.yml` 自动构建发布：
打包时剔除 `assets/*.mp4`（视频体积太大），线上视频位降级为封面图 + 在线体验按钮。

```bash
git push origin main        # 自动触发 Pages 部署
```

`vercel.json` 是备用部署配置（静态托管 + 资源长缓存 + 安全响应头），随时可以一键切到 Vercel。

### 改样式必读

`index.html` 里每个资源都带 `?v=日期_时分` 版本号。**改了 `style.css` 或 `app.js`，一定要把版本号一起往上抬**，
否则访客的浏览器会继续用缓存里的旧文件——改动「上线了但看不见」就是这么来的。

## 账号系统

页面上的登录 / 注册接的是独立后端 `auth-hub`（FastAPI + SQLite，端口 8100），
用户名唯一性靠数据库的 `UNIQUE COLLATE NOCASE` 约束保证，邀请码只存在服务端。
前端只保存令牌，不存用户表也不存密码。
